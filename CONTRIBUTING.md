# Contributing

For a change to a KPI, include the business rule, affected tables and expected result for a small order. Update the data dictionary, SQL, DAX and integrity checks together wherever the rule applies.

Run `python -m unittest -v test_data.py` from the repository root. For Fabric changes, record the runtime, affected notebook cell and reconciliation results. Remove credentials and customer identifiers from logs and screenshots before sharing.
